How I teach Java and Android

FTC robots run Java on Android, so I teach both together. Students learn the language in small steps, then use it right away on a real robot.

Java foundations

Students start with the language itself, before touching a robot.

  • Variables, data types, conditionals and loops.
  • Methods, classes and objects, explained with robot parts like a motor or a claw.
  • Small exercises, and reading error messages to fix problems themselves.
Java

Java on Android

The FTC Robot Controller is an Android app, so I show students how their code becomes a running app.

  • Setting up Android Studio and the FTC SDK, and finding their way around the project.
  • How Gradle builds the project and pulls in libraries.
  • Deploying to the Control Hub or Robot Controller over USB and Wi-Fi.
Android StudioFTC SDKGradle

Controlling the robot

Next, students turn Java into robot behavior.

  • OpModes for autonomous and driver-controlled (TeleOp) modes.
  • The hardware map, which links code to motors, servos and sensors.
  • Gamepad input and telemetry, with classes that organize each subsystem.
OpModesTelemetry

Tuning and teamwork

Last, we make the code reliable and easy to share.

  • PID control for smoother, more precise movement.
  • Reusable libraries, such as my own TeaLib, so teams stop rewriting the same code.
  • Git and GitHub, testing on the field, and reviewing each other's code.
